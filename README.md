# Spotify ↔ Yandex Music Sync

A lightweight Python daemon that **bidirectionally** syncs liked tracks between **Spotify** and **Yandex Music** every 2 hours.

---

## How it works

### Spotify → Yandex Music
1. Fetches the 50 most recently liked tracks from your Spotify account.
2. Checks the local cache (`synced_spotify_to_yandex.txt`) — if a track has already been processed, it is **skipped entirely** (no API calls).
3. Searches for each new track on Yandex Music and likes it.

### Yandex Music → Spotify
1. Fetches the 100 most recently liked tracks from your Yandex Music account.
2. Checks the local cache (`synced_yandex_to_spotify.txt`) — if a track has already been processed, it is skipped.
3. Searches for each new track on Spotify and adds it to your Liked Songs.

### Removal-Aware Logic
Once a track has been processed (found and liked), it stays in the cache permanently. This means:
- If you **remove a like** on Yandex, the daemon will **not** re-add it from Spotify.
- If you **remove a like** on Spotify, the daemon will **not** re-add it from Yandex.
- On the **very first run**, both libraries are snapshotted as a baseline — existing tracks are never touched.

## One-time setup: get your Spotify Refresh Token

Run `get_spotify_token.py` **once on your local machine** to authorize via browser
and get a long-lived `SPOTIFY_REFRESH_TOKEN`:

```bash
pip install spotipy
SPOTIFY_CLIENT_ID=xxx SPOTIFY_CLIENT_SECRET=yyy python get_spotify_token.py
```

Copy the printed `SPOTIFY_REFRESH_TOKEN` value into Coolify.

> **Important:** If you previously generated a token with only `user-library-read` scope,
> you need to regenerate it. The new version requires `user-library-modify` scope
> for Yandex→Spotify sync to work.

## Environment Variables

Set all four variables in your Coolify service settings:

| Variable | Description |
|---|---|
| `SPOTIFY_CLIENT_ID` | Your Spotify app's Client ID (from [Spotify Developer Dashboard](https://developer.spotify.com/dashboard)) |
| `SPOTIFY_CLIENT_SECRET` | Your Spotify app's Client Secret |
| `SPOTIFY_REFRESH_TOKEN` | Long-lived refresh token generated by `get_spotify_token.py` (must include `user-library-modify` scope) |
| `YANDEX_TOKEN` | Yandex Music OAuth token (see instructions below) |

Optional:

| Variable | Default | Description |
|---|---|---|
| `DATA_DIR` | `/data` | Directory for persistent cache files |

### How to get your Yandex Music token

The easiest method is the browser extension **"Yandex Music Token"** available for Chrome/Firefox.
Alternatively, use the `yandex-music` library's built-in helper:

```python
from yandex_music import Client
# Generates a token interactively
client = Client.from_credentials("your@email.com", "your_password")
print(client.token)
```

> **Note:** Keep all tokens secret and never commit them to version control.

## Deployment on Coolify (Oracle Cloud ARM64)

1. Push this repository to your Git provider (GitHub/GitLab/etc.).
2. In Coolify, create a new **Docker-based service** pointing to your repo.
3. Coolify will use the `Dockerfile` automatically — no extra build config needed.
4. Set the environment variables listed above.
5. **Mount `/data` as a persistent volume** so cache files survive container restarts.
6. Deploy. Check the **Logs** tab to see the sync daemon output.

The image is built on `python:3.11-slim` which is officially available for
`linux/arm64` (aarch64), so no cross-compilation flags are required.
